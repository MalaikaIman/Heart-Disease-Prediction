# Heart Disease Prediction Using Machine Learning

## Project Overview
This project aims to predict whether a patient has heart disease using machine learning techniques. The project uses the UCI Cleveland Heart Disease Dataset and applies a Decision Tree Classifier to classify patients as having heart disease or not.

## Objective
The objective of this project is to:
- Load and understand a real-world healthcare dataset.
- Perform data cleaning and preprocessing.
- Split data into training and testing sets.
- Train a machine learning classification model.
- Evaluate model performance using accuracy, confusion matrix, and classification report.

## Dataset
- Dataset: UCI Cleveland Heart Disease Dataset
- Total Records: 303
- Total Features: 14

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Jupyter Notebook

## Machine Learning Algorithm
- Decision Tree Classifier

## Project Workflow
1. Data Loading
2. Data Exploration
3. Missing Value Handling
4. Data Preprocessing
5. Train-Test Split
6. Model Training
7. Model Evaluation

## Results
- Model: Decision Tree Classifier
- Accuracy: 75.41%

## Evaluation Metrics
- Accuracy Score
- Confusion Matrix
- Classification Report

## Files Included
- Heart_Disease_Prediction.ipynb
- processed.cleveland.data

## Conclusion
The Decision Tree model successfully predicted heart disease using patient medical data and achieved an accuracy of approximately 75%. This project demonstrates the practical application of supervised machine learning in healthcare prediction.
